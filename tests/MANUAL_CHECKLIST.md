# 実機チェックリスト(iPhone Safari)

`node --test` はDOM・IndexedDB・Service Worker・マイクに触れないため、以下は実機で確認する。
**必ずホーム画面のアイコンから起動した状態でも確認すること** — standalone(PWA)モードは
Safariの通常タブと挙動が異なり、特に音声認識はこのモードでのみ失敗する既知の問題がある。

デプロイ直後は「更新するトースト」をタップし、反映されたことを確認してから始める。

## まず最初に: バージョン確認

**何を試すより先に、設定画面を開いてバージョンを見る。**
「アプリ」と「Service Worker」が**両方とも同じ最新版**になっていれば反映完了。

| 表示 | 意味 | 対処 |
|---|---|---|
| 両方が最新版で一致 | 正常。テストを始めてよい | — |
| ⚠ 更新が中途半端です | 古いキャッシュのJSが使われている | 完全終了→開き直す。駄目ならアイコン削除→再追加 |
| `Service Worker: 応答なし(古いバージョン)` | v13以前のまま | 完全終了→開き直す |

> 不具合を報告するときは、この2行をそのまま伝えてもらえると切り分けが一発で済む。

## 音声確認(タップで切り替え)

| # | 手順 | 期待する結果 |
|---|---|---|
| 1 | マイクをタップ | 赤く点滅し、「🎤 聞き取り中」トーストが出る |
| 2 | 子どもの名前を1人分言う | タイルが緑に光ってスクロールし、確認済みカウンタが増える。**成功トーストは出ない** |
| 3 | **再タップせず続けて5人以上言う** | 全員が確認済みになり、**ボタンは赤いまま**(再レンダリングでボタンが死ぬ回帰の確認) |
| 4 | 15秒以上黙ってから、また名前を言う | 自動再開しており認識される。黙って死んでいない |
| 5 | もう一度マイクをタップ | 停止し、「音声で◯人確認」の集計トーストが1回だけ出る |
| 6 | 名簿にない言葉を続けて言う | トーストは4秒に1回だけ。**誰も確認済みにならない** |
| 7 | 設定でマイクを拒否してからタップ | 理由が `(webkit/standalone/secure)` のような診断付きで表示される |
| 8 | 機内モードにしてタップ | 4秒以内に必ず何かメッセージが出る(無反応で放置されない) |
| 9 | マイクON中に画面ロック/アプリ切替→戻る | マイクがOFFになっている |
| 10 | マイクON中に「終了」「途中退出」「点呼を追加」を開く | マイクがOFFになっている |
| 11 | マイクONのまま3分放置 | 「マイクを自動で止めました」が出てOFFになる |

> #7 の診断文字列は原因切り分けに使う。`none/...` ならその端末は音声認識に非対応、
> `.../standalone/...` でだけ失敗するならPWAモード固有の問題。報告時はこの文字列も伝える。

## 呼び方を覚えさせる(別名)

iOSの音声認識は名簿がひらがなでも漢字を返すため(「やまだ はなこ」→「山田花子」)、
そのままでは永久に一致しない。聞き取った言葉を登録して一致させる機能。

| # | 手順 | 期待する結果 |
|---|---|---|
| 1 | 反応しない子の名前を言う | `「山田花子」は分かりませんでした` のように**実際の聞き取り結果**が出る |
| 2 | 続けてその子のタイルをタップ | 確認済みになり、`「山田花子」を ◯◯ さんの呼び方として覚えますか?` が出る |
| 3 | 「覚える」をタップ | 登録され、`取り消す` 付きのトーストが出る |
| 4 | 次の点呼タブでもう一度同じ名前を言う | **今度は一致する**(タイルが緑に光る) |
| 5 | アプリを完全終了して開き直す | 別名が残っている(名簿→その子→「音声での呼び方」で確認) |
| 6 | **漢字1文字の名前**(舞・蓮・葵など)で #1〜#4 | 1文字でも同じように覚えられる |
| 7 | ひらがなで聞き間違えられた場合 | 提案は**出ない**(漢字を含む聞き取りだけが対象)。手動で登録する |
| 8 | 確認済みのタイルをタップして外す | 提案は**出ない**(訂正であって、言った子の指定ではないため) |
| 9 | 名前を言って、**ゆっくりタイルを探してから**タップ(20〜30秒かけてよい) | 提案が出る。急いで探す必要はない |
| 9b | 名前を言って45秒以上放置してからタップ | `時間切れです` と**理由が表示される**(無言で終わらない) |
| 9c | マイクをONにしたまま30秒以上黙る | マイクが勝手に切れない |
| 10 | 名前を言った後、別の名前を言ってからタップ | 提案は**最新の**聞き取り結果のもの1つだけ。積み上がらない |
| 11 | 提案が出ている間に点呼タブを切り替える | 提案が消える |
| 12 | **今日休んでいる子**が既に持つ別名を、別の子に覚えさせようとする | `◯◯ さんと紛らわしいため覚えられません` と拒否される |
| 13 | 提案トーストが出ている8秒間 | 記録ボタン・マイクボタンが**押せなくならない** |
| 14 | 名簿→子ども→「音声での呼び方」 | チップをタップして削除できる。手入力で追加もできる |
| 15 | 設定→名簿を書き出し→読み込み | 別名が消えていない |

## ストレージ(写真のゴミ掃除)

| # | 手順 | 期待する結果 |
|---|---|---|
| 1 | 更新後の初回起動 | 設定→端末ストレージの使用量が、過去の蓄積分だけ**減っている** |
| 2 | お散歩を1回やって終了→再起動→使用量を確認 | 1回あたり約1MB増え続けることがない |
| 3 | 設定→「不要な写真データを整理する」 | 件数がトーストで出る。名簿の写真は消えていない |
| 4 | お散歩の**最中**に設定から手動整理を実行 | 進行中のお散歩のタイル写真が消えない |
| 5 | 名簿画面を開く | 全員の写真が正常に表示される(roster:の写真が誤削除されていない) |

## 回帰確認

- 点呼タイルのタップで確認/解除ができる
- 点呼中のスクロール位置が、タップしても先頭に戻らない
- 途中退出・退出取り消しが動く
- 履歴のCSV書き出しが動く
- 名簿のJSONバックアップ書き出し/読み込みが動く
